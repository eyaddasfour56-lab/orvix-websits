## Full listing description

ORVIX is the production proof for a ready-to-brand ecommerce and operations platform designed around Egyptian retail workflows. The buyer receives a licensed source snapshot and a clean deployment in accounts they control, without inheriting ORVIX customer data or seller-owned service credentials.

The system covers the complete customer journey: product discovery, variants, stock, cart, discounts, checkout, account registration, saved addresses, order history, reorder, cancellation, returns, verified reviews, and identity-protected tracking. The protected admin area covers orders, fulfillment, products, inventory, customers, cashflow, analytics, discounts, reviews, waitlists, brand settings, SEO, risk signals, recovery, exports, and role-aware controls.

The platform is built with Next.js 16, React 19, TypeScript, Supabase, and Vercel. The repository contains 50+ storefront, customer, and admin route screens, 90+ server/API route handlers, and 20+ ordered database migrations. English and Arabic customer experiences are included.

### Included

- Licensed source-code snapshot for one production brand
- Complete Supabase migration set
- Clean buyer-controlled Supabase and Vercel setup
- Initial brand, product, delivery, promotion, and SEO configuration
- Environment-variable template without production secrets
- Technical walkthrough and acceptance checklist
- 30 calendar days of handover and defect support

### Not included

- ORVIX trademarks, logo, social accounts, or brand content
- Existing customer, order, analytics, chat, review, or waitlist data
- Seller-owned hosting, database, courier, email, SMS, AI, or payment accounts
- Provider credits, contracts, KYC approvals, or guaranteed third-party availability
- A second production brand, source redistribution, sublicensing, or template resale
- New features or ongoing maintenance after the agreed support period

### Important disclosure

This offer is for a working software platform and production demo. It is not presented as an established revenue-generating business. Any provider-dependent email, SMS, courier, or AI capability requires the buyer's own approved account.
